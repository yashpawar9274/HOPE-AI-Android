# Reference and adaptation notes

This HOPE AI V2.0 guide was informed by the staged engineering approach in:

- https://github.com/codeninjavik/lia-build-guide

The reference repository describes a Kotlin/Jetpack Compose voice-first Android
assistant and separates implementation into buildable phases. HOPE V2.0 uses an
original product identity, original logo, different package structure and a
different service architecture built around Supabase, Mem0 and Firebase Cloud
Messaging.

No LIA visual asset, application name, package name or private configuration is
included in this package.
